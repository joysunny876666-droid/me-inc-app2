# 手機版本 說明

## 資料夾結構

```
手機版本/
├── 程式碼/      # 手機版專用 JavaScript
├── 樣式/        # 手機版專用 CSS 樣式
└── 資料/        # 手機版相關文件與紀錄
```

## 目前狀態

目前手機版的 CSS 響應式設計整合在主要 `style.css` 中：

- **`@media (max-width: 767px)`** — 手機直向最佳化（卡片式橫向滑動 + 底部導覽列）
- **`@media (max-height: 500px) and (orientation: landscape)`** — 手機橫向模式
