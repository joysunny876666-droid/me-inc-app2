## 📋 第一大項目：人生股票系統優化

### 1. ✅ 重複項目日期信息顯示

**功能描述**：
在「日常任務」、「全部行程」、「重要事項」三個框中，重複性項目旁邊會顯示：
- 開始日期（MM-DD 格式）
- 重複頻率（每 N 日/週/月）
- 下次開始日期

**顯示格式範例**：
```
任務名稱
4/27 | 每 1 週 | 下次: 5/4
```

**實作位置**：
- `modules/02_tasks.js` → `createTaskEl()` 函式
- 第 458-505 行

**支援的重複類型**：
- ✅ 每日重複：顯示「每 N 日」
- ✅ 每週重複：顯示「每 N 週」+ 指定星期幾
- ✅ 每月重複：顯示「每 N 月」

---

### 2. ✅ 重複項目編輯邏輯重構

**功能描述**：
根據提供的流程圖，實作新的編輯邏輯：

#### 📌 編輯選擇：
當編輯重複項目時，系統會詢問：
1. **「僅此項目」**：只修改今天這一次，其他天保持不變
2. **「此項目與之後」**：根據是否勾選任務性，執行不同邏輯

#### 🔄 「此項目與之後」的邏輯：

##### 情況 A：未勾選任務性
- **行為**：從今天開始取代後續項目
- **實作方式**：
  1. 將舊的重複序列截止到「昨天」
  2. 建立新的重複序列從「今天」開始
  3. 新序列套用所有修改後的屬性

##### 情況 B：勾選了任務性
- **行為**：刪除整個重複序列
- **實作方式**：
  1. 完全刪除原本的重複任務
  2. 建立一個新的「單次任務」（今天的日期）
  3. 所有後續的重複項目都被移除

**實作位置**：
- `modules/06_calendar.js` → `updateRecurringFuture()` 函式
- 第 398-525 行

**用戶提示**：
- 任務性項目：顯示「✅ 任務性項目：已刪除整個重複序列，轉為單次任務」
- 一般項目：顯示「✅ 已從今天開始取代後續所有項目」

## 📊 第二大項目：視覺化流程圖系統

### 1. ✅ 今日流程圖 Modal

**功能描述**：
在「新增項目」頁面新增「📊 今日流程圖」按鈕，點擊後開啟流程圖視窗。

**介面設計**：
- **左側欄**：顯示今天需要完成的所有項目（排除甘特圖）
- **右側區域**：24小時時間軸，可拖放項目

**操作方式**：
1. **點擊項目**：開啟「設定時間對話框」
2. **拖動項目到時間軸**：自動帶入該時段時間，再由對話框確認

**實作位置**：
- `modules/08_flowchart_v4.js`（新建檔案）
- `index.html` 新增兩個 Modal：
  - `flowchartModal`：流程圖主視窗
  - `setTimeModal`：設定時間對話框

---

### 2. ✅ 與週行程連動

**功能描述**：
流程圖與週行程系統完全連動：
- 在流程圖中修改項目時間 → 週行程同步更新
- 在週行程中修改項目 → 流程圖同步更新

**實作方式**：
- 使用統一的 `saveState()` 機制
- 修改後同時呼叫：
  - `renderFlowchart()` - 更新流程圖
  - `renderWeeklySchedule()` - 更新週行程
  - `renderStartPage()` - 更新主頁

---

### 3. ✅ 設定時間對話框

**功能描述**：
當用戶點擊項目或拖動項目到時間軸時，彈出對話框讓用戶手動輸入時間。

**輸入欄位**：
- **開始時間**：必填
- **結束時間**：可選

**驗證規則**：
- 結束時間必須晚於開始時間
- 如果從時間軸拖動，自動帶入拖放位置的小時

**實作位置**：
- `modules/08_flowchart_v4.js` → `openSetTimeModal()` 函式
- `modules/08_flowchart_v4.js` → `handleSetTimeConfirm()` 函式

## 📖 使用指南

### 如何查看重複項目的日期信息？
1. 在主頁的任何任務列表中
2. 重複性項目下方會自動顯示：`開始日期 | 頻率 | 下次日期`

### 如何修改重複項目？
1. 點擊任務右側的「✏️」編輯按鈕
2. 修改所需屬性
3. 點擊「確認」
4. 系統會詢問修改範圍：
   - **僅此項目**：只改今天
   - **此項目與之後**：
     - 未勾選任務性 → 從今天起全部更新
     - 勾選任務性 → 刪除重複序列，轉為單次任務

### 如何使用今日流程圖？
1. 進入「新增選項」頁面
2. 點擊「📊 今日流程圖」按鈕
3. 在流程圖中：
   - **點擊左側項目** → 設定時間
   - **拖動項目到右側時間軸** → 快速設定時間段
4. 在彈出的對話框中輸入開始/結束時間
5. 點擊「確認」完成設定

## ⚠️ 重要提示

1. **任務性項目的編輯**：
   - 勾選任務性後選擇「此項目與之後」會刪除整個重複序列
   - 此操作不可撤銷，請謹慎使用

2. **日期計算**：
   - 「下次開始日期」基於當前日期和重複規則計算
   - 如果是「每週指定星期」模式，會自動找下一個符合的日期

3. **流程圖與週行程連動**：
   - 兩者共用相同的任務數據
   - 在任一處修改會立即同步到另一處
