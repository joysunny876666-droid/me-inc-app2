## 📖 5 分鐘上手

### 功能 1：查看重複項目信息 ⏰

**在哪裡看？**
- 主頁的「日常任務」
- 主頁的「全部行程」
- 主頁的「重要事項」

**會顯示什麼？**
```
任務名稱
4/27 | 每 1 週 | 下次: 5/4
```
- **4/27** = 開始日期
- **每 1 週** = 重複頻率
- **下次: 5/4** = 下次會出現的日期

---

### 功能 2：修改重複項目 ✏️

**步驟**：
1. 點擊任務右側的「✏️」
2. 修改任何你想改的內容
3. 點「確認」
4. 選擇修改範圍：

#### 選項 A：僅此項目 📅
- **效果**：只改今天這一次
- **其他天**：保持原樣

#### 選項 B：此項目與之後 🔄
會根據你有沒有勾選「任務性」而不同：

**沒勾選任務性**：
- ✅ 從今天開始，之後的都改成新設定
- ✅ 昨天和之前的保持原樣

**有勾選任務性**：
- ⚠️ 刪除整個重複序列
- ⚠️ 只保留今天這個單次任務
- ⚠️ 明天不會再出現

---

### 功能 3：使用今日流程圖 📊

**如何開啟？**
1. 點擊「新增選項」
2. 點擊「📊 今日流程圖」按鈕

**介面說明**：
```
┌─左側───────┬─右側───────────────┐
│ 今日項目   │  00:00 ─────      │
│            │  01:00 ─────      │
│ □ 讀書     │  02:00 ─────      │
│ □ 運動     │  ...              │
│ □ 寫作     │  09:00 ■ 讀書     │
│            │  ...              │
└────────────┴───────────────────┘
```

**兩種設定時間的方法**：

#### 方法 1：點擊項目
1. 點擊左側任一項目
2. 在對話框中輸入時間
3. 點「確認」

#### 方法 2：拖動項目
1. 從左側拖動項目
2. 拖到右側的時間軸（例如 14:00）
3. 在對話框中確認時間
4. 點「確認」

**同步更新** 🔄：
- 在流程圖設定的時間
- 會自動出現在「週行程」中
- 也會更新主頁的任務顯示

## 💡 常見問題

### Q1: 重複項目的「下次日期」是怎麼算的？
**A**: 根據你設定的重複規則：
- **每日**：今天 + N 日
- **每週**：今天 + N 週（如有指定星期幾，會找最近符合的日期）
- **每月**：今天 + N 月

### Q2: 什麼時候該選「僅此項目」？
**A**: 當你只想改今天這一次，例如：
- ❌ 今天感冒，取消今天的運動
- ❌ 明天還是要運動，只是今天不行

### Q3: 什麼時候該選「此項目與之後」？
**A**: 當你想永久改變這個項目，例如：
- ✅ 把「每天 8:00 運動」改成「每天 7:00 運動」
- ✅ 從今天開始都要提早一小時

### Q4: 為什麼勾選「任務性」會刪除重複序列？
**A**: 因為任務性代表「做完就不用再做」：
- 任務性 = 未完成會一直出現
- 所以改成單次任務才符合邏輯
- 完成後就不會再出現了

### Q5: 流程圖為什麼看不到甘特圖的項目？
**A**: 根據設計需求，流程圖只顯示「日常項目」：
- ✅ 在流程圖中：只有日常任務
- ✅ 在週行程中：包含日常 + 甘特圖項目

### Q6: 我設定的時間會存到哪裡？
**A**: 所有數據都會：
- 💾 自動儲存到本地
- ☁️ 自動同步到雲端（如有啟用）
- 🔄 同步到所有視圖（主頁、週行程、流程圖）

## ⚠️ 注意事項

### 1. 任務性項目的編輯
```
⚠️ 勾選任務性 + 選「此項目與之後」
→ 會刪除整個重複序列
→ 此操作無法撤銷
```

### 2. 時間設定驗證
```
❌ 結束時間必須晚於開始時間
✅ 開始：09:00，結束：10:00 → OK
❌ 開始：10:00，結束：09:00 → 錯誤
```

### 3. 週行程連動
```
流程圖 ←→ 週行程
（修改任一處，另一處會自動更新）
```

## 🎯 實戰範例

### 範例 1：每天早上的晨跑

**建立任務**：
- 名稱：晨跑
- 重複：是
- 頻率：每 1 日
- 時間：07:00-08:00
- 分數：10

**在主頁會顯示**：
```
晨跑 ⏰ 07:00-08:00
06-23 | 每 1 日 | 下次: 06-24
```

---

### 範例 2：改變晨跑時間

**原本**：每天 07:00-08:00  
**想改成**：每天 06:00-07:00

**步驟**：
1. 點「✏️」編輯
2. 改時間為 06:00-07:00
3. 選「🔄 此項目與之後」
4. ✅ 從今天開始都是 06:00 了

---

### 範例 3：今天臨時取消

**今天感冒不跑**：
1. 點「✏️」編輯
2. 選「📅 僅此項目」
3. 直接取消 or 改時間
4. ✅ 只有今天變更，明天還是會跑

---

### 範例 4：使用流程圖規劃今天

**想安排今天的時間**：
1. 點「📊 今日流程圖」
2. 看到左側有：讀書、運動、寫作
3. 拖「讀書」到 09:00
4. 拖「運動」到 14:00
5. 拖「寫作」到 19:00
6. ✅ 今天的時間規劃完成！
